Caranya:

## 1. Database (phpMyAdmin)
1. Jalankan XAMPP Control Panel Start Apache dan MySQL.
2. Buka http://localhost/phpmyadmin tab Import pilih `database/db_covid_indonesia.sql`.

## 2. Backend PHP
1. Salin folder `api/` ke `C:\xampp\htdocs\dashboard-covid\api` (Folder `dashboard-covid` bikin sendiri).

## 3. Frontend
npm install
npm run dev            
buka http://localhost:8080
